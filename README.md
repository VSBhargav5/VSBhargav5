| Pain | Project |

| Prompt changes silently break LLM behavior | → **PromptGuard** |
| Decisions & owners get lost after meetings | → **DecisionLog** |
| EdTech ranking needs reliable incremental ETL | → **LMS-ETL-PIPELINE** |

Each repo is meant to read as production-minded: clear README, local-first CLI, tests where they matter, CI when useful.
